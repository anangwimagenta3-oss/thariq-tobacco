THARIQ TOBACCO — WEBSITE PROFIL & DASHBOARD INTERNAL

Cara membuka:
1. Ekstrak ZIP.
2. Buka index.html dengan Chrome/Edge/Firefox.
3. Klik tombol Admin untuk membuka dashboard internal.

Catatan:
- Ini prototipe statis, belum dipublikasikan ke internet.
- Dashboard menyimpan data di localStorage browser/perangkat yang digunakan.
- Gunakan Ekspor data untuk membuat cadangan JSON secara berkala.
- Belum ada autentikasi admin, database server, atau sinkronisasi antarperangkat.
- Website publik hanya berisi informasi usaha umum. Tidak ada katalog, harga, promosi, checkout, atau alur pemesanan produk tembakau.
- Pastikan seluruh informasi alamat, jam, kontak dan konten diperiksa sebelum dipublikasikan.
- Untuk hosting/domain, diperlukan pembelian atau layanan hosting yang sesuai dan pemeriksaan kepatuhan sebelum peluncuran.
